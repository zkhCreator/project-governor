# Support

Use the repository's GitHub issue forms for public support:

- Bug reports: reproducible runtime, rule, installation, or documentation problems
- Feature requests: proposed capabilities with a concrete use case and project boundary
- Questions: installation and usage questions that do not contain confidential information

Before opening an issue, search existing issues and run the latest `main` branch when practical. Include Project Governor, Python, Codex CLI, Xcode, and macOS versions when they affect the result.

Do not include proprietary source code, live credentials, personal health data, private screenshots, or unredacted `.xcresult` contents in public issues.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be reported through a public issue.
